# 计算方法实验代码集

📚 欢迎来到《地球物理与计算方法》课程的实验代码库！本仓库汇集了多个经典数值分析算法的C++实现，旨在帮助学习者深入理解并掌握这些重要的数学工具。通过实际编程练习，我们将探索如何利用计算机解决复杂的科学计算问题。

## 📂 项目结构

本项目包含以下核心模块：

- [`1.1-newton.cpp`](1.1-newton.cpp) - **牛顿插值法实现**
  - 插值多项式的构建与应用，用于估计未知点处函数值。
  
- [`2.1-composite.cpp`](2.1-composite.cpp) - **复化梯形求积公式实现**
  - 数值积分方法之一，适用于连续函数在给定区间上的近似积分。

- [`3.1-eula.cpp`](3.1-eula.cpp) - **改进欧拉法求解微分方程**
  - 常微分方程初值问题的数值解法，特别适合处理非线性系统。

- [`4.1-bisectionMethod.cpp`](4.1-bisectionMethod.cpp) - **二分法求根实现**
  - 非线性方程求根的经典算法，简单且可靠。

- [`5.1-gass.cpp`](5.1-gass.cpp) - **高斯-塞德尔迭代法求解线性方程组**
  - 线性代数中常用的迭代解法，效率较高。

- [`6.1-thomas_algorithm.cpp`](6.1-thomas_algorithm.cpp) - **追赶法求解三对角线性方程组**
  - 特殊矩阵形式下的高效解法，广泛应用于工程领域。

## 📝 主要算法及其应用场景

- **插值法**: 使用牛顿插值多项式来预测离散数据点之间的函数行为，常用于信号处理等领域。
- **数值积分**: 复化梯形公式为积分运算提供了便捷途径，尤其当解析解难以获得时。
- **常微分方程数值解**: 改进欧拉法能够有效模拟动态系统的演化过程，如物理仿真。
- **非线性方程求根**: 二分法是寻找方程实根的基本手段，具有良好的收敛性和稳定性。
- **线性方程组求解**: 高斯-塞德尔迭代法和追赶法则分别针对一般稀疏矩阵及特殊三对角矩阵提供了解决方案。
